# Smart Expense Tracker

## Project Overview

Smart Expense Tracker is a web-based expense management system developed using Python Flask and MySQL.

It allows users to manage their expenses, set budgets, view expense records, generate reports, and manage their profile.

## Features

- User Registration
- User Login and Logout
- Dashboard
- Add Expense
- View Expenses
- Edit Expense
- Delete Expense
- Budget Management
- Expense Reports
- Category-wise Expense Analysis
- Profile Management
- Session-based Authentication

## Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- JavaScript
- Chart.js
